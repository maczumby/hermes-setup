This guide is your step by step of setting up an agent on Filament.

If you get stuck anywhere, raise your hand.

Before you start

  1. If you haven't already, request a LinkedIn export for a fun demo. It takes LinkedIn a while to prepare, so kick it off before anything else: Get a copy of your data → pick the top option, the larger archive (not the "want something in particular" one below it) → Request. You'll use it in part 4.
  2. A GitHub account. Not strictly required (everything you'll download today is public), but useful for filing an issue or submitting feedback. Make one here.
  3. A ChatGPT account ($20 Plus). You can use any LLM for your agent, but ChatGPT lets you use subscription tokens for it, which is handy if you don't want to accidentally run up a bill.

What we’ll do today

Introduce you to the concept, help you build the basics, customize it with a couple of example use cases, and send you off inspired to build your own.
