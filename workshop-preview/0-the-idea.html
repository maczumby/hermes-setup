What's an agent, and why Hermes?

A short read before you build anything: what an agent is, and why we start people on Hermes.

What's an agent?

You already use a model like Claude or ChatGPT: you ask, it answers, then it waits. An agent is a model that keeps working on its own. It remembers what you tell it, and it can run on a schedule or chase a goal without you steering each step. The big assistants are all adding this. Today you build one you own.

The words you'll hear:
  • Model — the brain you talk to (Claude, GPT, Sol). The part you can swap.
  • Agent — a model plus memory, scheduling, tools, and a personality.
  • Framework — what you build the agent with. Hermes is one; OpenClaw is another.
  • Virtual machine — a computer you rent in the cloud, separate from your laptop.

What's Hermes?

Hermes is the framework you build the agent with. It wraps a model with the memory, scheduling, tools, and identity that make it an agent. The main alternative is OpenClaw, which came first. Hermes came later and added more guardrails: rules for who's allowed to talk to the agent, more caution when it edits its own code, and a smaller set of add-ons rather than thousands of community plugins. That's why we start people on it.

Why build your own?

With Claude or ChatGPT, the agent's memory and settings live inside someone else's product. With Hermes the agent is just files on a machine you control, so you can swap the model underneath whenever you want. Start on ChatGPT's Codex today, move to Claude or Sol tomorrow, and nothing you've set up is lost. Run out of one provider's tokens and you switch to another. The big models would rather keep you locked in; this way you aren't.

You can also put it in a room with other people, which Claude and Codex can't do yet. Your agent gets an identity others can talk to in shared channels, answering within rules you set. That's most of the second half of this course.

When you don't need one

If you just want to check your email, use Claude. Just your calendar, use Codex. You want something like Hermes when you're after an agent that's more independent, closer to a teammate that gets better over time and that you and people you trust can talk to. If that's not what you're building, you don't need any of this.

Why a blank computer

An agent that can write and run its own code, sitting on your laptop, can reach everything else on your laptop: your files, your tax returns, whatever is there. You've probably heard the story of someone's whole inbox getting wiped. That's the risk when the agent lives where your data does. So it doesn't. In Part 1 you put your agent on a rented, blank machine with none of your data on it, and you hand over only what you choose.
