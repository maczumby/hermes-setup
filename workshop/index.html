Stuck anywhere? Raise your hand. That's what we're walking around for.

Before you start: three things to have ready

  1. A GitHub account. If you don't have one, make one now. Takes two minutes.
  2. Your LinkedIn export, started now. It takes LinkedIn a few minutes to prepare, so kick it off before anything else: LinkedIn → Settings → Data privacy → Get a copy of your data → pick the archive that includes Connections → Request. You'll use it in part 6.
  3. Access to the network tool, requested now. It lives in a private repo. Drop your GitHub username here and send the request. Access gets granted in batches during the talk, so file it early.
  4. A subscription login for the agent's brain. A ChatGPT, GitHub Copilot, or Grok subscription works. More on why in part 2.
